# 通用工具层

通用工具层提供所有模块共用的基础工具函数，包括日志记录、消息处理和错误管理等。

## 文件结构

- **logger.py**：日志工具，负责系统日志的记录和管理
- **message_utils.py**：消息处理工具，提供消息格式化、解析等功能
- **error_handling.py**：错误处理工具，提供异常捕获和处理机制
- **__init__.py**：模块初始化文件

## 主要功能

- 统一的日志记录机制
- 消息处理和转换工具
- 错误捕获和处理
- 提供其他通用辅助函数

## 设计要点

- 工具函数应当是无状态的
- 提供一致的接口和使用方式
- 注重性能和可重用性
- 易于扩展和维护
