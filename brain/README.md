# 脑功能模块层

本目录包含Abyss Core系统的脑功能相关模块，采用神经科学术语命名，模拟大脑的不同功能分区。

## 目录结构

- **att/**：注意力模块(attention)，负责注意力分配和消息优先级处理
- **pre/**：前额叶模块(prefrontal)，负责目的规划和目标设定
- **chat/**：对话模块，负责用户交互和对话生成

## 设计理念

- 采用神经科学术语命名，直观反映模块功能
- 各模块高内聚低耦合，便于扩展和维护
- 模拟大脑的信息处理流程，实现更自然的交互体验

## 模块间关系

- 注意力模块负责接收和筛选信息
- 前额叶模块根据信息确定行动目的
- 对话模块基于目的生成用户响应
- 各模块通过消息总线进行通信
