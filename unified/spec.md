# 统一 Agent 实验：一个循环，不再有分工

> 分支 `experiment/unified-agent`。与 `main` 的 PFCASession / ConversationSession / ReflectionSession
> 四道循环完全独立：本目录不 import `brain/`，只用标准库。

## 要验证的假设

**假设**：把"决策层 / 说话层"的进程级分工去掉，改成一个 agent + 一个上下文 + 一次生成，
行为连贯性和响应速度会变好，而"策略污染"（说话时带着算盘）能被一个**字段级**约束挡住。

**与 main 的关键差异**

| | main | 本实验 |
|---|---|---|
| 循环 | 5 个 HeavySession，靠 `pfc_handoff` 接力 | 1 个循环 |
| 上下文 | 每腿从摘要重建 | 全程同一份 |
| 意图传递 | `purpose` ≤120 字 + `extra_info` | 不存在这道缝 |
| 工具 | 按 agent 划分，Conversation 看不到 PFCA 的工具 | 全部可见 |
| 隔离 | 进程/会话边界 | **字段边界**：`inner` 只进系统，`speech` 只进群 |
| 状态 | `GlobalSessionState._data` + 单例 reset 约定 | 显式 State 对象，所有变更走命名事务并落日志 |

## 三个不可谈判的设计点

### 1. 内心与正文是同一次生成的两半，不是一个前置阶段

模型每次必须同时给出 `inner`（怎么理解、想要什么、怕什么、多大把握）和 `speech`（真正说出口的，可为空）。

- `inner` 永不发出去，只喂给状态结算、反思、审计。
- `speech` 为空是合法动作（沉默）。
- 这不是"先想后说"的两拍，是一次输出的两个字段。**降延迟靠这个，不靠流水线。**

### 2. 隔离靠字段，不靠进程

main 的隔离是"Conversation 不知道策略"。本实验的隔离是"策略写在 `inner` 里，且被约束不可复述"。

代价必须写在这里：**这是约定，不是墙**。强模型九成守得住。守不住的形态是——她说出一句
只有知道算盘才成立的话。出现一次，观感损失大于接缝的全部收益。

所以本实验必须有检测：`inner` 与 `speech` 的语义重叠度超阈值时报警（见 `loop.py` 的 `leak_check`）。

### 3. 能力与权限仍要分层，即使只有一个 agent

分工没了，但"我能做"和"我有权定性"不能混。工具带 `authority` 标记：

- `capability`：查、看、记、等。随便用。
- `decision`：结束本轮、给人下结论、结算效益。**必须产出结算记录**（谁、何时、为何、结果），
  否则不算完成。

单个 agent 的自由度上限就落在这条线上：工具全开，但每一次定性都要留证。

## 自由度的真实边界

用户要的是"让她不被 PFC 限死"。所以本实验里没有"必须先决策再执行"的约束：

- 可以连续说，不需要每句回来请示。
- 可以自己决定何时沉默、何时结束。
- 可以查任何东西，不需要申请。
- `inner` 里的 `confidence=low` 不禁止行动，只改变一件事：**循环给她更少的连续轮数**
  （方向不确定时缩短反馈周期，而不是延长独白）。

## 已知会输的地方（先写下来，免得事后归因错误）

1. **长对话的一致性**。没有反思系统那种离线的经验沉淀，连续 50 轮后会飘。
2. **可解释性变差**。main 能回答"是谁决定这么说"，本实验只能回答"那一轮她心里写了什么"。
3. **无行为验收**。和 main 一样没有，但 main 至少能按层定位，这里只能整段看。

## 怎么判断实验成没成

不看功能列表，只看三条，读 20 条真实群聊回放：

1. 有没有"听起来在算计"的句子（`leak_check` 报警率）。
2. 有没有"记得上一条为什么那么说"（跨轮连贯）。
3. 延迟：一句话的端到端循环次数（目标 ≤2）。

任何一条明显变差，就说明接缝那 120 字是**过滤**而不是**损耗**，本实验可以直接收摊。
