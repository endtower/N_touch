# 启动器固定位置

当前项目唯一日常启动入口：`dist/Abyss/AbyssLauncher.exe`。
也可以双击项目根目录的 `启动Abyss.cmd`。

`dist/Abyss/` 中的 DLL、语言目录和三个 `*_internal` 是运行依赖，需要与 EXE 一起保留。`core.exe`、`manager.exe`、`ingress.exe` 是启动器管理的后台程序，日常无需单独打开。

此目录的 `abyss-data-dir.txt` 内容为 `../..`，继续使用项目根目录的数据、配置、人格、SnowLuma 登录信息和日志。`ABYSS_DATA_DIR` 环境变量若已设置，则优先使用其指定目录。移动整个项目不会改变相对目录关系；不要只移动单个 EXE。

1. 在独立的构建目录生成并验收 WPF 发布文件、三个后台 EXE 及其运行时。`launcher/bin/` 和 `build/` 仅作构建中间目录。
2. 从现有启动器选择“退出全部”，确认启动器和受管程序停止。
3. 将验收后的应用文件更新到 `dist/Abyss/`，保留 `abyss-data-dir.txt` 和所有运行数据。不要递归删除整个运行目录；旧 `*_internal` 可在停机后作为应用依赖替换。
4. 以后均使用相同入口，不新增 `*-preview` 日常运行目录，不把 `launcher/bin/` 作为交付位置。

`scripts/assemble_dist.py` 当前仍是独立的便携数据包组装流程，不能直接代替上述完整 WPF 发布步骤。
